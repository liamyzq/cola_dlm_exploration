## Pilot and independent confirmation

The pilot includes all F pairs collected in fixed root order, at most32.
Each pair gets4 A and4 B noises shared across its two candidates. The pilot
manifest will link each saved pair to its originating experiment and commit.
It is generated using acceptance records only, without looking at futures.

Confirmation uses the128 fixed articles in the independent corpus with8 A
and8 B samples per live root, K at most2. There is no target number of accepted
confirmation pairs and no replacement of failed or terminated roots. K=1
receives ordinary reference continuations and contributes cost and coverage;
H_token is undefined for that root. Primary inference is conditional on
accepted pairs with95% source-document clustered bootstrap intervals.
Report actual attempted, live, paired and measured roots alongside the estimate.

Generation always charges the full32-token continuation horizon. Statistic
padding after EOS does not erase model calls. Root encoding, native reference
construction, all proposals/rejections, reconstruction, both future splits,
and observed elapsed time are retained separately for complete cost accounting.
Natural passage continuation has no task reward or deployment verifier here;
its H_token result alone cannot support H1b, H2 or H3.

## Bounded cache-path localization

If the pilot shows an interpretable positive distribution effect, localize it
on the first eight accepted development roots in the fixed manifest, without
selecting by observed effects. Use the same 4 A and4 B noise arrays. Compare
consistent reference/reference and candidate/candidate states with DiT-only
and decoder-only counterfactual cache paths, all built by normal chronological
commits from the common pre-block history. No cache tail is manually patched.
The counterfactuals are diagnostics, not native candidates.

The cap is8 roots x4 states x8 futures=256 trajectories. Reuse128 already
computed pilot trajectories where available, so at most128 additional futures
are needed. Report whether each changed path preserves the emitted IDs.
Do not replace the primary native comparison with a counterfactual effect.
If no positive effect is interpretable in the pilot, record localization as
not activated under this rule; the fixed independent confirmation still runs.

## Scheduling the same pilot in two parts

To use a free GPU while ordered candidate collection continues, the first 16
accepted F pairs are frozen in a part1 manifest and measured immediately.
The remaining final accepted pairs form part2. Both use the same settings,
4 A/4 B samples, root-specific seeds, and one 512-future combined cap. The
main agent does not inspect formal effect outputs until F collection is
terminal. Candidate collection continues under its unchanged fixed cap and
acceptance-only rule. The final manifest must equal the disjoint union of
both parts; scheduling does not add a cohort or a setting search.
